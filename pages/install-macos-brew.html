How to Install Homebrew on macOS (Step-by-Step Guide)

Homebrew is the most widely used package manager for macOS. It allows you to install, update, and manage command-line tools and applications with simple commands.

This guide walks through the correct steps to install Homebrew on a Mac.

1. Check macOS Compatibility

Homebrew officially supports macOS Sonoma (14) or newer, although it may still run on some older versions without official support.

To check your macOS version, open the terminal application and enter the following command.

sw_vers

You should see something like:

ProductName:    macOS
ProductVersion: 15.x.x
BuildVersion:   ...

Homebrew officially supports macOS Sonoma (14) or newer, although it may still run on some older versions without official support.

2. Install Xcode Command Line Tools

Homebrew requires Apple's developer tools.

Run:

xcode-select --install

A popup will appear asking you to install the command line developer tools. Click Install and wait for it to finish.

To verify the installation:

xcode-select -p

Expected output:

/Library/Developer/CommandLineTools

3. Install Homebrew

Open Terminal and run the official installation script:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

The installer will:

  • download Homebrew
  • install it to the correct directory
  • configure permissions
  • verify dependencies

You may be prompted to enter your macOS password.

4. Add Homebrew to Your PATH

After installation, Homebrew may ask you to add it to your shell profile.

For Apple Silicon Macs (M1/M2/M3/M4/M5 etc.)

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

For Intel Macs

echo 'eval "$(/usr/local/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/usr/local/bin/brew shellenv)"

5. Verify the Installation

Check that Homebrew installed successfully:

brew --version

Example output:

Homebrew 4.x.x

You can also run a diagnostic check:

brew doctor

If everything is correct, you should see:

Your system is ready to brew.

6. Update Homebrew

Before installing packages, update Homebrew:

brew update

7. Install Your First Package

To test the installation, install a common tool like wget:

brew install wget

You can now use it:

wget https://example.com/file.zip

Common Homebrew Commands

Command Description
brew install <package> Install a package
brew uninstall <package> Remove a package
brew update Update Homebrew
brew upgrade Upgrade installed packages
brew upgrade <package> Upgrade specific package
brew list Show installed packages
brew search <name> Search for packages

Where Homebrew Installs Packages

Typical install locations:

Apple Silicon

/opt/homebrew

Intel Macs

/usr/local

Uninstall Homebrew (Optional)

If you ever want to remove Homebrew:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/uninstall.sh)"
